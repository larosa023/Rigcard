# Third-party components

- **PawnIO modules** `res/pawnio/AMDFamily17.bin`, `res/pawnio/IntelMSR.bin`: signed modules from https://github.com/namazso/PawnIO.Modules (release 0.2.11, as bundled by LibreHardwareMonitor), unmodified, licensed under the GNU LGPL 2.1 (`res/pawnio/COPYING`). They run inside the PawnIO driver, which you install separately (https://github.com/namazso/PawnIO.Setup).
- Code shared with the larosa023 suite (JSON reader, Direct2D helpers, themes, updater) comes from https://github.com/larosa023/Hangar.
