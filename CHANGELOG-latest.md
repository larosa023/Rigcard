## Rigcard 1.0.0

The first release: your PC build as one clean, shareable card.

- **Detects your hardware by itself**: CPU, GPU and VRAM, motherboard and BIOS, memory (size, speed, modules), drives, monitors, keyboard and mouse, Windows version. Rescan any time to see what changed.
- **Parts Windows can't see**: search-as-you-type picker for coolers, power supplies, cases, fans and peripherals, or type anything.
- **Live stats**: CPU and GPU temperature, clocks, load, power draw and uptime, read only while the window is open.
- **Benchmarks**: quick CPU single and multi-core, GPU compute, memory bandwidth and latency, storage read, write and 4K tests, with history. Import 3DMark, CrystalDiskMark, Geekbench and Cinebench scores.
- **Card design**: 10 styles, full color, font, layout and corner control, photo cropping, blurred photo backgrounds. Save and share styles as JSON.
- **Export** PNGs for Discord and Reddit, square posts, Instagram portrait, phone wallpapers and 4K. Copy the image straight to the clipboard.
- **Share links**: an instant quick link, or a hosted page (a secret gist on your GitHub) that updates when your build does, with optional live stats.
- **Privacy**: serial numbers, IP address, user name and location stay off the card unless you turn them on.
- Themes shared with the rest of the suite, live theme changes from Hangar, a built-in updater with Stable and Beta channels, hash-verified downloads and automatic rollback.
